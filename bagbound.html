BAGBOUND

Chargement du jeu…

Comment ça marche

  • Le combat est entièrement automatique : tout se joue dans le rangement de ton sac. Chaque objet a une barre qui se remplit ; pleine, l'objet frappe, protège ou soigne.
  • Glisse les objets de la réserve vers le sac. Touche un objet pour le tourner (ou R / clic droit, M pour le miroir). Touche longtemps (ou survole à la souris) pour voir ce qu'il fait.
  • Les objets se renforcent entre voisins : la pierre à aiguiser affûte les armes qui la touchent, la torche enflamme leurs coups, la pointe de l'épée de fer (flèche jaune) renforce l'objet posé devant elle. Le petit + vert indique un objet qui reçoit un bonus.
  • Pendant le combat, les potions sont la seule action : touche pour boire, touche longtemps (ou clic droit) pour lancer sur l'ennemi. Vide, une potion devient une bouteille… qu'on peut lancer aussi.
  • Touche un ennemi pour inspecter son sac. Vitesse x1 / x2 / x4, pause avec Espace, Entrée lance le combat.
  • Version d'essai (atelier) : choisis une rencontre, du gobelin jusqu'à la Gardienne des ronces. La carte, la boutique, les fusions et l'histoire arrivent ensuite.
